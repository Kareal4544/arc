## 🎯 About this software

Arc helps you organize your digital files and projects. The tool acts as a hub for your work. It tracks changes and saves your progress automatically. This ensures you never lose work on your active projects. Designers, writers, and students use this tool to maintain a clean workspace on their computers.

## ⚙️ System requirements

Your computer needs to meet these basic standards to run the application:

* Windows 10 or Windows 11
* 4 GB of RAM
* 200 MB of free storage space
* A stable internet connection for the first setup

## 🛠️ Using the software

Once you launch the app, you see a blank dashboard. Click the New Project button to get started. Give your project a name and choose the folder where you want to keep your files. 

The software automatically detects when you create or modify a file within that folder. It keeps a history of these changes. You can view this history by clicking the clock icon on the left sidebar. This lets you revert to older versions if you make a mistake.

## 🛡️ Troubleshooting

Most issues arise from missing permissions. If the app fails to start, try these steps:

* Right-click the app icon on your desktop.
* Select Run as Administrator.
* Check your antivirus settings to ensure it does not block the application.
* Update your Windows operating system to the newest version.

If the problem persists, close the app and restart your computer. This clears temporary memory issues that sometimes prevent programs from launching.

## 📁 Managing your project files

Arc creates a small hidden file in each project folder. This file tracks your history. Do not delete or move this file. If you remove it, the app loses the link to your progress history. You can still access your files as normal, but you will no longer see the version history for that project.

## 📈 Performance tips

If you have many active projects, the app might take a moment to load upon startup. You can improve performance by closing old projects you no longer use. Right-click a project name and select Remove from Dashboard to stop the app from monitoring that directory. Keeping your project folders on a fast drive, such as an SSD, will also improve search speeds and response times.
